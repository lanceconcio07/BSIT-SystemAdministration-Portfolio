# Enterprise Infrastructure Planning — Week 2

## Project Overview

This project presents the initial IT Infrastructure Plan for **ABC Startup Solutions**, a newly established software development company with 20 employees operating in a single office floor.

The project focuses on planning the company's hardware, software, network infrastructure, system administration requirements, security, backup strategy, and future expansion.

## Learning Objectives

Through this project, I practiced the following skills:

* Analyzing organizational IT requirements
* Preparing hardware, software, and network inventories
* Designing an enterprise network topology
* Understanding system administration roles
* Preparing infrastructure recommendations
* Creating professional technical documentation
* Using GitHub for portfolio documentation

## Company Scenario

ABC Startup Solutions is a software development company with four departments:

| Department             | Employees |
| ---------------------- | --------: |
| Information Technology |         5 |
| Human Resources        |         4 |
| Finance                |         5 |
| Sales                  |         6 |
| **Total**              |    **20** |

The company started with no computers, server, network, internet infrastructure, or security policies. The purpose of this project is to design the required IT infrastructure from the ground up.

## Hardware Inventory Summary

The proposed hardware infrastructure includes:

* 16 Desktop Computers
* 4 Laptops
* 1 Server
* 1 Router
* 1 Network Switch
* 2 Network Printers
* 4 UPS units
* 2 Wireless Access Points
* 1 NAS Storage
* 2 External Backup Drives
* 20 Monitors

These resources are intended to support employee workstations, centralized services, networking, printing, backup, storage, and power protection.

## Software Inventory Summary

The proposed software environment includes:

* Windows 11 Pro
* Ubuntu Server LTS
* Microsoft Office
* Visual Studio Code
* Git
* GitHub Desktop
* VirtualBox
* Google Chrome
* Microsoft Defender
* AnyDesk
* 7-Zip

These applications support productivity, software development, system administration, security, remote support, and file management.

## Network Inventory Summary

The proposed network infrastructure includes:

* ISP Modem
* Router
* Firewall
* Network Switch
* Wireless Access Points
* Patch Panel
* CAT6 Ethernet Cables
* RJ45 Connectors

The network is designed to provide reliable internet access, wired connectivity, wireless connectivity, and basic network security.

## Challenges Encountered

One of the most challenging parts of the project was designing the enterprise network diagram. It required understanding how the Internet, ISP modem, router, firewall, switch, server, printer, wireless access point, and departments should be connected.

Another challenge was determining appropriate hardware and network resources for a 20-employee company while keeping the proposed infrastructure practical and scalable.

## Reflection

This project helped me understand that system administration involves more than troubleshooting computers. Proper planning is necessary before purchasing equipment or deploying infrastructure.

I learned how to analyze business requirements, prepare IT inventories, design a network topology, and document technical decisions. The project also improved my understanding of security, backup strategies, system administration roles, and infrastructure scalability.

The experience will help me become more prepared for future IT projects and develop better planning and problem-solving skills as a future System Administrator.
